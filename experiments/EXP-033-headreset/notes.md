# EXP-033 headreset — 세대마다 공격 출력층을 새로
날짜: 2026-11-06 · 기반: EXP-030 조건 A(EXP-028 A 규칙, 교체 없음, 밀기 묶기 1.25, 새 공격 리그 0.2, 매 스텝 소음), EXP-029, EXP-032 · 학습: 맥(`launch.sh`, 조건 2개 × 시드 3개 동시, 스레드 2), 92분 · 스텝: 세대당 공격 2M + 수비 2M + 새 공격 2M, 12세대

## 왜
- EXP-032: 유지 소음은 어떤 크기로도 배운 공격을 옮기지 못했다. 흔들려서 빈 쪽으로 새는 플레이는 OL과 맞지 않아 야드가 안 나온다.
- EXP-029: 출력층만 새로 한 공격은 2M 스텝 안에 새 망처럼 가운데를 찾았다(-6.4 → 0.5M 4.6 → 2M 8.4야드).
- 지금 공격은 1세대에 고른 쪽을 끝까지 안 바꾼다. EXP-030 A에서 라인을 왼쪽으로 넘는 비율(`explore_side.py`, 1 / 3 / 6 / 12세대): s0 100 / 100 / 100 / 100%, s1과 s2 0 / 0 / 0 / 0%.
- 미리 정한 다음 후보(EXP-032 notes). 사용자: "결과 확인후 다음 방향 추천대로 진행해줘."

## 가설
- 출력층을 새로 하면 평균 밀기가 0에서 다시 출발한다. OL과 러너가 그 세대의 수비에 맞는 플레이를 처음부터 함께 맞춘다. 수비가 한쪽으로 쏠렸으면 다른 쪽을 찾는다. 숨은 층(배치를 보는 부분)은 남아서 처음부터 하는 것보다 빠르다.
- 걱정: 매 세대 -6야드에서 다시 시작하니 2M 스텝 안에 다 못 배울 수 있다. 그러면 수비가 덜 배운 공격만 상대하게 된다. 그래서 B는 3세대마다 한다.
- 자신은 반반보다 조금 낮다. 길은 옮기겠지만 배치를 읽는 데까지 갈지는 모른다.

## 시도 (규칙은 EXP-030 A와 같음. `config.yaml`로 확인)
- `train/selfplay.py --reset-head-every N`: 공격 2세대, 2+N세대, ...를 배우기 직전에 출력층을 새 망처럼 초기화하고(직교, gain 0.01, 편향 0) 흩어짐 std를 1로 되돌린다. 숨은 층, 가치망, 최적화기 상태는 그대로(EXP-029 head와 같다). 새 공격 리그와 수비는 바꾸지 않는다.
- A: `--reset-head-every 1` 매 세대(2~12세대). 로그에서 초기화 11번 확인.
- B: `--reset-head-every 3` 2, 5, 8, 11세대. 초기화 4번 확인.
- `reset_head`를 `train/policies.py`로 옮겼다. `explore_side.py`에 왼쪽으로 넘는 비율을 더했다. 테스트 80개 통과. 벤치 134만 스텝/초.

## 놀라운 점
- **초기화는 길을 옮겼다. 다만 좌우가 아니라 가운데와 바깥 사이로.** A의 3세대는 시드 3개 모두 가운데 구역으로 넘었다(구역 통과 1세대 0.6 / 0.1 / 0.1% → 3세대 100 / 99 / 100% → 6세대 0 / 0 / 0%). 그 세대 수비는 가운데가 비어 있었다. 가운데로 곧장 뛰는 단순 러너가 3세대 수비 상대 4.7 / 4.0 / 7.5야드, 1세대와 6세대 수비 상대로는 -0.6~2.8야드다. 초기화하지 않은 B의 3세대는 구역 통과 10 / 1 / 0%로 바깥에 남았다. 수비가 6세대에 가운데를 막자 A는 다시 바깥으로, 원래 가던 그 쪽으로 돌아갔다. 출력층을 새로 한 공격은 그 세대 수비의 빈 곳을 세대 사이에 찾아간다. 한 플레이 안에서 배치를 읽지는 않는다.
- 쪽(왼쪽 / 오른쪽)은 숨은 층에 남아 있는 것 같다. 출력층이 0에서 출발해도 12세대 내내 같은 쪽을 다시 골랐다(A s1 3세대만 예외: 가운데 구역 안에서 왼쪽으로 조금 넘음).
- #story `clips/A_s2_middle_g3_vs_outside_g6.mp4`(시드 0 플레이 1) — 위 화면: A s2 3세대 공격 vs 3세대 수비. 초기화한 공격이 가운데로 곧장 뚫고 터치다운(32플레이 중 31). 아래 화면: 같은 시드 6세대. 수비가 가운데를 막자 다시 오른쪽 바깥으로 돌다 -3야드 태클(32플레이 중 터치다운 19). "빈 곳은 찾아가지만, 매 플레이 보고 고르지는 않는다".
