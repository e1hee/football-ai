# EXP-029 unstick — 오래된 공격은 왜 길을 못 옮기나
날짜: 2026-11-05 · 기반: EXP-028 조건 A 12세대(공격 24M 스텝, 교체 없음) · 학습: 맥(`launch.sh`, 12개 동시, 스레드 1), 약 20분 · 스텝: 공격만 4M, 수비는 12세대로 고정

## 왜
EXP-028 A의 24M 스텝 공격은 12가지 배치 모두에서 바깥으로 가고, 같은 OL로 직진만 하는 단순 러너보다 못했다(5.58 / 2.61 / 4.66 vs 6.73 / 4.24 / 4.83야드). 같은 수비 상대로 처음부터 2M 스텝만 배운 공격은 가운데로 가서 8.37 / 5.37 / 8.58야드(구역 통과 90 / 7 / 99%)였다. 망 안의 무엇이 길을 못 옮기게 하는지 모르면, 읽기를 가르치는 다음 실험도 같은 벽에 막힌다. 사용자: "추천 진행".

## 가설
- 오래된 공격을 그대로 더 학습하면 못 옮긴다(EXP-026에서 EXP-025 공격을 2M 더 학습해도 구역 통과 0~0.1%).
- 어디서 막혔는지는 모른다. 후보는 셋이다.
  - 행동의 흩어짐(탐색)이 바닥 0.8에 붙어 있어 다른 길을 안 시도한다.
  - 마지막 출력층이 한쪽으로 굳었다.
  - 숨은 층(배치를 보고 특징을 뽑는 부분)이 굳었다.

## 시도
시드 3개 × 4가지. 각자 자기 12세대 수비(고정) 상대로 4M 스텝을 학습하고, 0.5M마다 저장한다. 하네스는 EXP-028 분석의 새 공격과 같다(`scripts/recovery_test.py`, 환경 512개, 시드 0, 흩어짐 바닥 없음). 바꾸는 것만 한 칸씩 늘린 사다리다.
| 이름 | 숨은 층 | 출력층 | 흩어짐(std) 시작값 |
|---|---|---|---|
| warm | 그대로 | 그대로 | 0.8 (그대로) |
| noise | 그대로 | 그대로 | 1.0 (새 망과 같음) |
| head | 그대로 | 새로(SB3 기본 초기화) | 1.0 |
| fresh | 새로 | 새로 | 1.0 (기준) |
- 코드: `recovery_test.py`에 `--reset-head`(출력층만 새 망처럼 초기화), `--save-each`(0.5M마다 저장) 추가. 테스트 `test_reset_head_keeps_the_hidden_layers`.
- 측정: `measure.py`. 저장한 공격마다 학습 상대 수비와 2048플레이, 라인을 넘는 곳(가운데 ±3.6야드 구역 통과)과 야드.

## 판정 기준 (학습 전에 정함)
2M 스텝 시점, 시드별. 합격선은 내 판단이다.
- **옮겨 갔다:** s0, s2(새 공격이 가운데로 가는 시드)에서 구역 통과 50% 이상, 그리고 시드 3개 모두 야드가 같은 실험 fresh보다 1야드 이상 낮지 않다. s1은 새 공격도 바깥(7%)이라 야드만 본다.
- **유효성:** fresh가 s0, s2에서 구역 통과 50% 이상이어야 한다. 아니면 하네스가 EXP-028 분석과 달라진 것이라 판정하지 않는다.
- **해석:** 옮겨 간 가장 작은 칸이 원인이다.
  - warm이 옮겨 가면: 망은 멀쩡하다. 문제는 셀프플레이 일정(수비가 계속 바뀌는 상대) 쪽이다.
  - noise부터: 탐색 부족. 다음은 흩어짐 바닥을 올리거나 세대마다 되돌리기.
  - head부터: 출력층이 굳었다. 다음은 세대마다 출력층 초기화.
  - fresh만: 숨은 층이 굳었다. 다음은 공격을 주기적으로 새로 만들되 수비가 따라잡을 시간을 주는 방식.
- 판정에 안 쓰지만 기록: 4M 시점 결과(시간을 더 주면 옮겨 가나), 0.5M마다 곡선, 구역 안 / 밖 야드.
- 재현: `launch.sh` → `PYTHONPATH=. uv run python experiments/EXP-029-unstick/measure.py`.

## 결과
**판정: head가 옮겨 간 가장 작은 칸이다.** warm, noise는 못 옮기고, 출력층만 새로 하면 새 망처럼 가운데를 찾는다. 유효성 통과(fresh 구역 통과 s0 89.4%, s2 99.6%). 결과 `measure.log`, `measure.json`, 학습 기록 `runs/`.

2M 시점, 구역 통과 % / 야드 (s0 / s1 / s2). 시작점(24M 공격)은 0 / 3.7 / 0.1%, 5.52 / 2.58 / 4.68야드.
| | s0 | s1 | s2 | 판정 |
|---|---|---|---|---|
| warm | 0 / 9.60 | 4.0 / 3.16 | 0.1 / 5.86 | ✗ 구역 0%, s1 -4.4, s2 -2.7야드 |
| noise | 0 / 9.81 | 3.3 / 3.51 | 0 / 7.36 | ✗ 구역 0%, s1 -4.1, s2 -1.2야드 |
| head | 96.1 / 8.41 | 0 / 8.45 | 95.9 / 9.65 | ✓ |
| fresh | 89.4 / 8.11 | 1.3 / 7.59 | 99.6 / 8.57 | 기준 |

- **원인: 행동의 크기가 자라 탐색이 줄었다.** 시뮬은 길이가 1을 넘는 밀기(가속 명령)를 길이 1로 줄인다(`TeamSim.step`). 방향만 남는다. 그러니 망이 평균 밀기를 아무리 길게 내도 벌점이 없다. 24M 공격의 러너 평균 밀기 길이는 3.54 / 4.03 / 2.86, OL은 1.47 / 1.73 / 1.45다. 새 망은 러너 1.5~1.8, OL 0.6~0.8이다. 같은 흩어짐(std 0.8~1.0)이라도 긴 밀기는 덜 돌아간다. 흩어짐이 방향을 바꾸는 각도가 평균 26~32도, 새 망과 head는 52~59도다(`saturation.py`, `saturation.log`).
- **세대마다 자랐다.** EXP-028 A 러너 밀기 길이: 1세대 1.76~1.90 → 3세대 2.23~2.45 → 6세대 2.64~3.31 → 12세대 2.86~4.03. 흩어짐이 바꾸는 각도는 62~63도 → 26~32도. EXP-024에서 넣은 흩어짐 바닥(`--min-std 0.8`)은 std만 지키고, 밀기가 길어지는 건 못 막는다.
- **noise가 안 통한 이유도 같다.** std를 0.8 → 1.0으로 올려도 바꾸는 각도는 32 → 34도뿐이다. head는 출력층을 새로 해서 밀기 길이가 새 망 수준으로 돌아간다.
- **오래된 공격도 배울 수는 있다.** 고정된 수비 상대로 warm s0은 0.5M 만에 5.52 → 8.48야드, 2M에 9.60야드로 fresh(8.11)보다 높다. 자기 방향(바깥)을 다듬는 건 빠르다. 다른 방향을 안 시도할 뿐이다.
- **새 망도 수비에 따라 바깥을 고른다.** s1은 fresh도 head도 0.5M에는 가운데(85 / 95%)였다가 2M에 바깥(1.3 / 0%)으로 옮겨 7.59 / 8.45야드다. 옮겨 갈 수 있는 망은 상대에 맞춰 방향을 바꾼다.
- 4M 시점(판정 외): warm 0 / 2.7 / 0.2%, 9.91 / 3.81 / 7.74야드. noise s1만 7.99야드로 올랐지만 여전히 바깥(구역 0%). head, fresh는 9.43~9.98야드.

## 놀라운 점
- "굳은 습관"이 망의 깊은 곳이 아니라 행동 크기 문제였다. 시뮬이 긴 밀기를 잘라 주니 망은 밀기를 계속 키웠고, 그만큼 흩어짐이 효과를 잃었다. EXP-024부터 흩어짐 바닥으로 탐색을 지킨다고 생각했는데 실제로는 지켜지지 않았다.
- 이 설명이 맞다면 EXP-026(학습 더 해도 가운데 0%)과 EXP-027(교체로 젊은 공격이 오면 방향이 바뀜)도 같은 원인으로 설명된다. 다만 같은 문제가 수비에도 있는지는 안 쟀다.
- 클립 없음: 이번 차이는 영상보다 숫자(밀기 길이, 흩어짐 각도)로 보인다. 영상용으로는 EXP-028 클립(24M 공격 바깥 vs 새 공격 가운데)이 같은 장면이다.

## 다음 시도
- 판정 해석(학습 전 기준): 출력층. 측정으로 더 좁히면 "출력층이 내는 밀기의 크기"다.
- 후보(사용자 결정 대기):
  1. 평균 밀기 크기를 막는다: 망이 내는 평균을 예를 들어 ±1.5 안으로 부드럽게 묶는다(출력에 스케일된 tanh). 흩어짐이 늘 방향을 바꿀 수 있다. EXP-028 A 규칙(교체 없음)으로 다시 학습해 밀기 길이, 좌우 전환, 단순 러너 대비 야드를 본다. 공격과 수비 모두에 적용.
  2. 세대마다 출력층 무게를 줄여 평균 밀기 길이를 1 근처로 되돌린다. 행동 방향은 거의 유지된다. 기존 체크포인트에도 쓸 수 있다.
  3. 세대마다 출력층 초기화: 매 세대 -6야드에서 다시 시작해 비싸다. 비추천.
- 추천은 1번이다. 원인을 직접 막고, 새 학습 하나로 판정할 수 있다.
