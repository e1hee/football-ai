# EXP-036 bait — 수비가 속이기를 배우나 (진행 중)
날짜: 2026-11-06 · 기반: EXP-034 조건 A · 학습: 맥(`launch.sh`, 조건 2개 × 시드 3개 동시, 스레드 2) · 스텝: 세대당 공격 2M + 수비 2M + 새 공격 2M, 6세대

## 왜
- EXP-034: 공격이 흐름을 읽게 됐다(수비가 한쪽으로 쏠리면 반대로). 그러면 수비는 쏠리는 척하다 돌아오는 것, 즉 속이기에 값이 생길 수 있다.
- 사용자: "둘 다 진행"(EXP-034 notes 다음 후보 2번).

## 미리 잰 것 (학습 없이, `scripts/flow_bait.py`)
- 흐름만 읽는 스크립트 러너(AI 블로커 + 1초에 수비가 움직인 반대쪽 5야드로)는 EXP-034 A의 AI 수비 상대로 -0.5~2.9야드뿐이다. 반대로(흐름 쪽으로) 가도 비슷하다(흐름 값 -1.1~+0.7). AI 수비는 1초까지 옆으로 0.15~0.34야드만 움직인다(몰아막기 1.15야드). 그래서 이 러너를 그대로 넣으면 수비는 이미 막고 있어 속일 이유가 없다.
- 그래서 상대를 바꿨다(`sim/team_policies.py with_flow_read`). 최신 AI 공격 그대로 뛰다가, 1초에 수비가 정해진 거리 넘게 한쪽으로 움직였으면 그때만 반대쪽 5야드로 꺾는다. 수비가 일부러 기울면 이 러너가 어디로 갈지 정할 수 있다. 그러면 속이기가 값을 가진다.
- 기울기 기준에 따른 EXP-034 A 6세대 수비 상대 값(s0 / s1 / s2): 꺾는 비율, 읽기 비용(그냥 AI - 읽는 AI), 꺾을 때 값(반대쪽 - 흐름 쪽)
  | 기준 | 꺾는 비율 | 읽기 비용 | 꺾을 때 값 |
  |---|---|---|---|
  | 0.25야드 | 16 / 59 / 38% | 1.00 / 1.17 / 1.75 | -2.7 / +3.3 / -2.7 |
  | 0.5야드 (A) | 0 / 24 / 1% | 0.00 / 0.16 / 0.13 | - / +4.1 / -2.4 |
  | 0.75야드 (B) | 0 / 0 / 0% | 0 / 0 / 0 | - |
- 0.25야드는 학습 전에도 이미 많이 꺾고 손해를 본다. 수비가 따로 배우지 않아도 평범하게 따라가는 움직임에 걸린다. 그래서 뺐다.
- 주의: "꺾을 때 값"은 AI 공격의 블로킹 방향과 섞인다(블로킹은 늘 가던 쪽으로 짜여 있다). 그래서 판정에는 꺾는 비율과 읽기 비용을 쓴다.

## 가설
- 수비 플레이의 30%가 이 러너면, 수비는 1초까지 일부러 한쪽으로 기울고 반대쪽을 지키는 걸 배운다(꺾는 비율 0 → 30% 이상, 읽기가 오히려 손해).
- B(0.75야드)는 기울기가 더 커야 해서 배우기 어렵거나, 배우면 더 뚜렷하다.
- 걱정: 수비가 속이기 대신 그냥 이 러너를 잘 막는 법(기울지 않기)을 배우면 꺾는 비율이 0 그대로다. 그건 "안 속이고 안 걸림"으로 적는다.
- 자신: 반반보다 낮다(3분의 1 정도).

## 시도 (규칙은 EXP-034 A와 같음. `config.yaml`로 확인)
- `train/selfplay.py --bait-share 0.3 --bait-min-lean X`: 수비가 배울 때 상대의 30%가 "최신 공격 + 흐름 읽기". 최신 공격 몫에서 뺀다(최신 공격 그대로 0.1 + 읽는 최신 공격 0.3, 이전 공격, 스크립트 0.3, 새 공격 리그 0.2). 공격 쪽 상대는 EXP-034 A 그대로(몰아막기 0.3). `metrics.csv`에 세대별 `yards_bait_reader_vs_tackler`.
- A: 기울기 기준 0.5야드. B: 0.75야드.
- 테스트 83개 통과(몰아막기 상대로는 매번 반대쪽으로 꺾음, 수비 리그 몫).

## 판정 기준 (학습 전에 정함)
6세대, 조건마다, 자기 6세대 수비 상대, 자기 기준으로. 시드 s0 / s1 / s2. 기준값은 위 표(EXP-034 A 6세대).
- 시드가 "속였다" = 꺾는 비율 30% 이상 그리고 읽기 비용 1.0야드 이상.
- 합격: 시드 2개 이상. 기준값 A 0 / 3, B 0 / 3.
- 안전장치(수비가 진짜 공격도 막아야 함): 같은 시드 터치다운 20~70% / 시간 초과 5% 이하, 이 러너 vs 갭 스크립트 수비 90% 이상, 스크립트 러너 vs 이 수비 30% 이하.
- 기록: 세대별(1 / 3 / 6) 꺾는 비율, 읽기 비용, 1초 기울기, 꺾을 때 값. 공격의 몰아막기 좌우 전환(6세대).
- 조건 비교: 둘 다 합격하면 읽기 비용이 큰 쪽. 하나만 합격하면 그쪽.
- 재현: `analyze.sh A 0.5`, `analyze.sh B 0.75`.
