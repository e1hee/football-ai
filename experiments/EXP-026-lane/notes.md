# EXP-026 lane — 길 열기 보상 (진행 중)
날짜: 2026-11-04 · 기반: EXP-025(역할 보상 그대로, 규칙 그대로) · 학습: 맥(`launch.sh`, 조건 2개 × 시드 3개 동시, 스레드 2) · 스텝: 실행당 48M(12세대)

## 왜
EXP-025에서 OL은 버티게 됐지만 러너는 틈을 안 쓴다. 사용자가 원한 건 "길을 벌려줘야 한다, 러셔가 최소 거리로 뛸 수 있도록", "러셔는 사이드로 뛸지 틈으로 뛸지 판단". → "ㅇㅇ ㄱㄱ"

기준값을 재 보니 고정 구역(가운데 ±3.6야드, 스냅 때 OL 폭 + 1야드) 통과가 EXP-025 **0.1%**, EXP-024 B 20%(0 / 21 / 39), 스크립트 16%다. EXP-025 노트의 "안쪽 11%"는 그 순간 OL 양 끝 사이로 잰 값이라, OL이 벌어지면 같이 넓어져 부풀려져 있었다.

## 가설
구역 안으로 넓게 지나갈 때 보너스를 주면 OL은 수비를 밀어 틈을 넓히고, 러너는 틈과 사이드 중 나은 쪽을 고른다.

## 시도 (규칙은 EXP-025와 같음, 보상만 추가. 코드로 확인)
값은 내 판단으로 정했다. 야드 1 = 보상 0.1.
- 러너가 라인을 **처음** 넘는 순간, 그곳이 구역 안이고 태클이나 아웃이 아니면 공격이 보너스를 받는다. 크기는 가장 가까운 수비까지 거리(3야드까지) × 보너스. 수비에는 안 준다.
- 한 플레이에 한 번이라 라인 뒤에서 기다려도 못 번다(EXP-010 전례). 구역 밖은 0이라 빈 사이드로 가도 못 번다.
- A: `--lane-bonus 0.05`(최대 1.5야드어치). B: `--lane-bonus 0.1`(최대 3야드어치). 크기를 몰라 둘 다 돌린다.

## 판정 기준 (학습 전에 정함)
12세대, 조건별, 시드 평균. 기준값은 [role_EXP025.json](role_EXP025.json). 합격선은 내 판단이다.
| 지표 | EXP-025 | 합격선 | 참고 B / 스크립트 |
|---|---|---|---|
| 1. 라인을 넘은 플레이 중 구역 통과 | 0.1% | 30% 이상, 어느 시드도 85% 넘지 않음(양쪽을 다 써야 판단) | 20% / 16% |
| 2. 라인까지 경로 비율 | 1.55 | 1.40 이하 | 1.43 / 1.31 |
| 3. 러너가 라인 1야드+ 뒤일 때 수비가 1.5야드 안에 온 플레이 | 70% | 60% 이하 | 74% / 33% |
| 유지: OL 혼자 달리기 | 1.4% | 2.5% 이하 | |
| 유지: 다시 블록 | 60% | 55% 이상 | |
| 유지: LB 일찍 | 9.8% | 11% 이하 | |
| 안전장치: 같은 시드 터치다운 / 시간 초과 | 26~54% / 0% | 시드마다 20~70% / 5% 이하 | |
| 안전장치: 이 러너 vs 스크립트 수비 / 스크립트 러너 vs 이 수비 | 98% / 16% | 90% 이상 / 30% 이하 | |

- 두 조건 모두 합격이면 작은 보너스(A)를 기본으로 한다.
- 1번만 오르고 3번이 그대로면 러너만 옮겨 간 것이다. 영상과 수비 고정 비교(`scripts/role_cross.py`)로 OL이 실제로 틈을 여는지 본다.
- 판정에 안 쓰지만 기록: 틈이 넓을 때 구역으로 더 가는지(`gap_if_box`, `gap_if_out`), 통과 때 공간(`room_at_cross`), 붕괴, 새 망, 좌우 차이, 선수별 가치, 평균 야드.
- 주의: 지표 1은 보너스를 준 행동 자체라 오르는 게 당연하다. 스크립트 16%도 약한 수비 상대의 값이라 목표가 아니다. 지표 1이 올라도 실제 야드가 나빠지면 보너스에 끌려간 것으로 본다.
