# EXP-025 roles — 포지션별 역할 보상 (진행 중)
날짜: 2026-11-04 · 기반: EXP-024 B(노이즈 유지 + 상대 절반 좌우 뒤집기, 규칙 그대로) · 학습: 맥(`launch.sh`, 시드 3개 동시, 스레드 3) · 스텝: 실행당 48M(12세대)

## 왜
사용자: "OL은 러닝백이 뒤에 있을 때 앞으로 달려나갈 필요가 없다. 버티고 DL이 러셔에게 돌진 못하게 막고, 동시에 길을 벌려줘야 한다. 러셔는 사이드로 뛸지 틈으로 뛸지 판단한다. DL은 뚫고 들어가려 하고, LB는 틈을 파고들거나 러셔 움직임을 보며 태클 기회를 엿본다. 급하게 돌진할 필요가 없다." → "추천대로 진행해줘."

지금 보상은 공(러너) 야드 하나다(`sim/team.py`의 `gained`). OL 자기 전진은 점수에 안 들어가고, 역할도 없다. 측정(`scripts/slot_value.py`): OL 5명을 전부 세워도 야드 변화가 -0.8 ~ -1.6이고(러너를 세우면 -10 ~ -11), 15슬롯 중 9개는 |0.44| 이하다. 큰 값은 러너가 가는 쪽 OL뿐이다. 반대쪽 OL은 뭘 해도 점수가 안 변한다.

## 가설
역할을 보상으로 직접 말해 주면 OL은 상대 없이 달리지 않고 다시 막으러 가며, LB는 일찍 백필드로 들어가지 않는다. 경기가 망가지지 않으면(안전장치) 러너의 판단도 나중에 볼 수 있다.

## 시도 (규칙은 EXP-024 B와 같음, 보상만 다름. 코드로 확인)
모든 값은 내 판단으로 정했다. 야드 1 = 보상 0.1.
- `--blocker-shaping 0.03`: 수비 없이 비어 있는 OL이 빈 수비와 러너 사이 선까지 멀수록 낮은 잠재 보상(EXP-011 값). 다시 막으러 가는 쪽으로 끈다. 공격만.
- `--ol-run-cost 0.01`: 러너가 라인 뒤에 있는 동안, OL이 블록 없이 라인 1야드+ 앞에서 앞으로 움직이고 2.5야드 안에 안 막힌 수비가 없으면 스텝당 0.01(1초에 1야드어치). 공격만. 수비를 밀거나 LB에게 올라가는 전진은 벌받지 않는다.
- `--lb-rush-cost 0.01`: 러너가 라인 2야드+ 뒤에 있고 LB가 라인을 넘어 러너에게서 2.5야드+ 떨어져 있으면 스텝당 0.01. 수비만. 러너 가까이에서 태클하러 가는 건 벌받지 않는다.
- 평가는 전부 공 야드와 위치로 잰다. 역할 보상은 지표에 안 들어간다.
- 러너와 DL에는 새 보상을 안 줬다. 러너의 판단과 DL 돌파는 공 야드로 이미 보상된다.

## 판정 기준 (학습 전에 정함)
같은 12세대끼리 비교한다. 기준값은 EXP-024 B 12세대([role_B.json](role_B.json), `scripts/role_report.py`). 시드 평균이고 합격선은 내 판단이다.
| 지표 | B 12세대 | 합격선 | 스크립트 참고 |
|---|---|---|---|
| 1. OL이 상대 없이 앞으로 달리는 시간 | 5.3% (5 / 5 / 6) | 2.5% 이하 | 0% |
| 2. 블록 끝난 뒤 1초+ 남았을 때 다시 블록 | 40% (42 / 47 / 32) | 60% 이상 | 95% |
| 3. 러너가 라인 1야드+ 뒤일 때 수비가 1.5야드 안으로 접근한 플레이 | 74% (72 / 67 / 84) | 60% 이하 | 33% |
| 4. LB가 일찍 백필드에 있는 시간 | 22% (32 / 14 / 20) | 11% 이하 | 5% |
| 안전장치: 같은 시드 터치다운 | 41~54% | 시드마다 20~70% | |
| 안전장치: 시간 초과 | 0% | 5% 이하 | |
| 안전장치: 이 러너 vs 스크립트 수비 터치다운 | 98% | 90% 이상 | |
| 안전장치: 스크립트 러너 vs 이 수비 터치다운 | 19% | 30% 이하 | |

- 1~4와 안전장치를 모두 만족하면 합격. 그러면 EXP-024 B 위에 역할 보상을 기본으로 두고 24세대로 늘릴지 정한다.
- 일부만 만족하면 어느 역할이 남았는지 보고 그 역할만 고친다. OL 지표가 안 움직이면 팀 정책 하나의 한계일 수 있으니 선수별 정책을 다시 후보로 올린다.
- 경기가 망가지면(안전장치 불합격) 비용을 줄이기 전에 어떤 꼼수인지 클립으로 먼저 본다(EXP-010 전례).
- 판정에 안 쓰지만 기록: 러너가 틈 앞에 왔을 때 옆 공간과 가장 넓은 틈(1.4 / 0.9 / 0.8야드, 4.0 / 2.9 / 3.0야드), 라인까지 경로 비율(1.55 / 1.44 / 1.31), 안쪽 통과(21 / 40 / 65%), 라인 도달(58 / 56 / 46%), DL 돌파(1.5초 라인 뒤 0.58 / 0.63 / 0.57야드), 세대별 붕괴, 새 망 시험과 좌우 차이(B 12세대도 같이 잼), 선수별 가치(`scripts/slot_value.py`).
- 주의: 지표 1은 비용을 준 행동 그 자체라 내려가도 당연하다. 진짜 시험은 2, 3번이다. 스크립트는 약한 상대(스크립트 수비)에서 잰 값이라 목표가 아니라 참고다. 12세대는 길이를 줄인 거르기 단계라 최종 실력 판단이 아니다.
