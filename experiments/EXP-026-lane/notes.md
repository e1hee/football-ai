# EXP-026 lane — 길 열기 보상: 두 조건 모두 불합격, 대신 진짜 문제를 찾았다
날짜: 2026-11-04~05 · 기반: EXP-025(역할 보상 그대로, 규칙 그대로) · 학습: 맥(`launch.sh`, 조건 2개 × 시드 3개 동시, 스레드 2), 61분 · 스텝: 실행당 48M(12세대)

## 왜
EXP-025에서 OL은 버티게 됐지만 러너는 틈을 안 쓴다. 사용자가 원한 건 "길을 벌려줘야 한다, 러셔가 최소 거리로 뛸 수 있도록", "러셔는 사이드로 뛸지 틈으로 뛸지 판단". → "ㅇㅇ ㄱㄱ"

기준값을 재 보니 고정 구역(가운데 ±3.6야드, 스냅 때 OL 폭 + 1야드) 통과가 EXP-025 **0.1%**, EXP-024 B 20%(0 / 21 / 39), 스크립트 16%다. EXP-025 노트의 "안쪽 11%"는 그 순간 OL 양 끝 사이로 잰 값이라, OL이 벌어지면 같이 넓어져 부풀려져 있었다.

## 가설
구역 안으로 넓게 지나갈 때 보너스를 주면 OL은 수비를 밀어 틈을 넓히고, 러너는 틈과 사이드 중 나은 쪽을 고른다.

## 시도 (규칙은 EXP-025와 같음, 보상만 추가. 코드로 확인)
값은 내 판단으로 정했다. 야드 1 = 보상 0.1.
- 러너가 라인을 **처음** 넘는 순간, 그곳이 구역 안이고 태클이나 아웃이 아니면 공격이 보너스를 받는다. 크기는 가장 가까운 수비까지 거리(3야드까지) × 보너스. 수비에는 안 준다.
- 한 플레이에 한 번이라 라인 뒤에서 기다려도 못 번다(EXP-010 전례). 구역 밖은 0이라 빈 사이드로 가도 못 번다.
- A: `--lane-bonus 0.05`(최대 1.5야드어치). B: `--lane-bonus 0.1`(최대 3야드어치). 크기를 몰라 둘 다 돌린다.

### 왜 안 됐나 (학습 전 기준에 없던 추가 조사)
**1. 버그는 아니다.** 보너스만 끈 쌍둥이 시뮬과 비교해 보상 차이를 쟀다([scripts/lane_check.py](../../scripts/lane_check.py)). 코드대로 지급된다. 다만 12세대 지급 플레이는 A 3.0 / 0.0 / 0.1%, B 0.0 / 0.4 / 0.0%다. 받아 본 적이 거의 없다.

**2. 러너는 가운데에 있다가 떠났다.** 구역 통과(시드별):
| | 1세대 | 3세대 |
|---|---|---|
| EXP-025 (보너스 없음) | 98 / 87 / 0% | 0.0 / 0.0 / 0.1% |
| A | 0 / 97 / 55% | 0.2 / 0.0 / 0.1% |
| B | 0 / 100 / 0% | 0.5 / 0.2 / 0.1% |

보너스 없이도 초기에 가운데로 갔으므로, 1세대의 가운데 통과는 보너스 효과로 볼 수 없다. 러너는 처음부터 가운데에 서 있어서 직진하면 구역을 지난다.

**3. 그런데 가운데는 지금 열려 있다.** 같은 12세대 수비를 고정하고 2M 스텝만 새로 학습한 공격([offense_mix_A.json](offense_mix_A.json), [offense_mix_B.json](offense_mix_B.json), [offense_mix_EXP025.json](offense_mix_EXP025.json)):
| | 학습한 공격 | 새 공격 |
|---|---|---|
| EXP-025 야드 / 구역 통과 / 수비 접근 | 2.60 / 0.1% / 70% | 9.91 / 100% / 3% |
| A | 4.13 / 3.9% / 61% | 9.51 / 100% / 8% |
| B | 2.69 / 0.5% / 75% | 9.97 / 100% / 0% |

EXP-024 B 24세대도 새 공격 구역 통과 100 / 31 / 100%([checks/fresh_box_earlier.log](checks/fresh_box_earlier.log)). 보너스가 없어도 그렇다. 새 공격의 경로 비율은 1.02~1.11, 사용자가 말한 "최소 거리"다.

**4. 러너만의 문제가 아니라 OL도 다르다.** 수비 고정, 러너와 OL을 바꿔 끼운 평균 야드([scripts/offense_mix.py](../../scripts/offense_mix.py)):

|---|---|---|---|
| 학습 러너 + 학습 OL | 2.60 | 4.13 | 2.69 |
| 새 러너 + 학습 OL | 4.04 | 1.00 | 4.42 |
| 학습 러너 + 새 OL | 3.46 | 5.01 | 2.11 |
| 새 러너 + 새 OL | 9.91 | 9.51 | 9.97 |

가운데로 직진만 하는 단순 러너로 OL 효과만 떼어 보면 **시드 9개 모두** 새 OL이 낫다:
| 가운데 직진 러너 | EXP-025 | A | B |
|---|---|---|---|
| 학습 OL | 4.34 / 4.62 / 2.06 → 3.67 | 0.10 / 2.26 / 0.72 → 1.03 | 4.25 / 0.25 / 5.29 → 3.26 |
| 새 OL | 8.07 / 7.40 / 9.71 → 8.39 | 5.76 / 9.35 / 9.97 → 8.36 | 8.62 / 8.65 / 10.00 → 9.09 |

틈 폭(러너가 라인 2야드 앞일 때 수비 사이 가장 넓은 간격, 시드 평균): 학습 OL과 학습 러너 EXP-025 3.67 / B 3.34야드, 학습 러너에 새 OL만 끼우면 4.94 / 5.58야드. 새 OL은 러너가 안 써도 틈을 더 넓힌다.

**5. 습관은 더 학습해도 안 풀린다.** EXP-025 12세대 공격을 같은 수비 상대로 2M 스텝 더 학습([continue/box.log](continue/box.log)): 야드는 5.12 → 6.81, 2.46 → 5.41, 0.23 → 9.74로 늘지만 구역 통과는 0.0 / 0.1 / 0.0%. 새 공격과 똑같은 하네스, 똑같은 스텝이고 시작점만 다르다. 학습 능력을 잃은 건 아니고, 바깥을 더 잘 돌게 될 뿐 가운데는 안 시도한다.

**해석(내 추론이다).** 초반에 가운데로 가던 공격이 수비에 막혀 바깥으로 옮기고, OL도 바깥 러너에 맞춰 학습한다. 이후 공격이 가운데를 다시 시도하지 않으니 수비는 가운데를 안 지켜도 벌을 안 받는다. 양쪽이 서로의 습관에 맞춘 채 굳어 있다. 탐험 잡음(`--min-std 0.8`)은 스텝마다 흔들릴 뿐 계획을 바꾸지 않는다. 그래서 보너스를 키워도 러너가 안 가는 곳이면 받을 일이 없어 효과가 작을 것이다. 보너스를 더 크게 시험한 건 아니다.

**단서.** 새 공격의 10야드는 수비를 고정한 결과다. 수비가 적응하면 가운데도 다시 막힐 수 있다(1→3세대 기록이 그런 모습). 가운데가 정답이라는 뜻이 아니다. "지금 학습한 공격이 양쪽을 다 쓸 줄 모른다"는 뜻이다. 러너 교체와 틈 폭 비교도 수비가 그 조합을 처음 보는 상태에서 쟀다.

### LB가 돌아가는 러너를 쫓는가 (사용자 질문, 판정과 무관)
"러셔가 돌아가면 LB도 길목으로 쫓아가 태클해야 한다, 보상이 충분한가?" 12세대, [scripts/lb_chase.py](../../scripts/lb_chase.py), 원자료 `checks/lb_chase_*.json`.
- 보상 구조: LB만의 보상은 없다. 수비 전체가 공 야드의 음수를 받는다(야드당 0.1). 터치다운 하나를 라인에서 막으면 약 1.0을 번다.
- 벌점: LB당 0.01/스텝 = 초당 1야드어치. LB가 라인 뒤, 러너가 라인 2야드+ 뒤, 러너와 2.5야드+ 떨어졌을 때. **쫓아가는 LB도 조건에 들면 낸다.** 내가 만든 모순이다.
- 벌점이 쫓기를 막는다는 증거는 약하다. 쫓는 스텝(2야드/초+, 러너 0.5초 뒤 위치 쪽 약 45도 안) 중 벌점 대상은 가까운 LB 1~61%, 먼 LB 0~9%(시드별). 쫓는 비율은 벌점 없는 EXP-024 B 12세대(가까운 LB 9 / 6 / 11%)보다 EXP-025(9~28%)가 낮지 않다. OL 보상도 달라서 깨끗한 비교는 아니다. 크기로도 터치다운 한 번 막으면 약 10초치 벌점이 나온다.
- 바깥으로 돈 플레이의 태클 중 LB 몫은 66~90%다. LB가 이미 주 태클러다.
- 대체 시험: LB 둘을 스크립트 추격으로 바꾼다. 러너가 바깥으로 도는 순간부터면 평균 야드 EXP-025 2.60 → 2.71, A 4.13 → 3.52, B 2.69 → 2.94로 뚜렷한 이득이 없다. 처음부터면 8.23 / 8.81 / 7.73으로 무너진다. 사용자의 "급하게 돌진할 필요 없다"와 맞다. 스크립트 추격이 좋은 추격이라는 보장은 없고, 공격이 적응하기 전의 일회성 비교다.
- 사용자가 본 것과 맞는 부분: 먼 LB가 첫 1초에 쫓는 비율은 9개 중 7개가 15% 이하, 가까운 LB와 러너 거리도 1초 뒤 줄어든 건 9개 중 4개다. 선수별 가치도 A, B 시드 6개 중 4개가 LB 하나만 5야드+, 다른 하나는 1.2야드 이하다. LB 둘 중 하나가 일을 거의 다 한다. 왜 그런지는 아직 모른다.
