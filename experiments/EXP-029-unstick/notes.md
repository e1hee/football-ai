# EXP-029 unstick — 오래된 공격은 왜 길을 못 옮기나 (진행 중)
날짜: 2026-11-05 · 기반: EXP-028 조건 A 12세대(공격 24M 스텝, 교체 없음) · 학습: 맥(`launch.sh`, 12개 동시, 스레드 1) · 스텝: 공격만 4M, 수비는 12세대로 고정

## 왜
EXP-028 A의 24M 스텝 공격은 12가지 배치 모두에서 바깥으로 가고, 같은 OL로 직진만 하는 단순 러너보다 못했다(5.58 / 2.61 / 4.66 vs 6.73 / 4.24 / 4.83야드). 같은 수비 상대로 처음부터 2M 스텝만 배운 공격은 가운데로 가서 8.37 / 5.37 / 8.58야드(구역 통과 90 / 7 / 99%)였다. 망 안의 무엇이 길을 못 옮기게 하는지 모르면, 읽기를 가르치는 다음 실험도 같은 벽에 막힌다. 사용자: "추천 진행".

## 가설
- 오래된 공격을 그대로 더 학습하면 못 옮긴다(EXP-026에서 EXP-025 공격을 2M 더 학습해도 구역 통과 0~0.1%).
- 어디서 막혔는지는 모른다. 후보는 셋이다.
  - 행동의 흩어짐(탐색)이 바닥 0.8에 붙어 있어 다른 길을 안 시도한다.
  - 마지막 출력층이 한쪽으로 굳었다.
  - 숨은 층(배치를 보고 특징을 뽑는 부분)이 굳었다.

## 시도
시드 3개 × 4가지. 각자 자기 12세대 수비(고정) 상대로 4M 스텝을 학습하고, 0.5M마다 저장한다. 하네스는 EXP-028 분석의 새 공격과 같다(`scripts/recovery_test.py`, 환경 512개, 시드 0, 흩어짐 바닥 없음). 바꾸는 것만 한 칸씩 늘린 사다리다.
| 이름 | 숨은 층 | 출력층 | 흩어짐(std) 시작값 |
|---|---|---|---|
| warm | 그대로 | 그대로 | 0.8 (그대로) |
| noise | 그대로 | 그대로 | 1.0 (새 망과 같음) |
| head | 그대로 | 새로(SB3 기본 초기화) | 1.0 |
| fresh | 새로 | 새로 | 1.0 (기준) |
- 코드: `recovery_test.py`에 `--reset-head`(출력층만 새 망처럼 초기화), `--save-each`(0.5M마다 저장) 추가. 테스트 `test_reset_head_keeps_the_hidden_layers`.
- 측정: `measure.py`. 저장한 공격마다 학습 상대 수비와 2048플레이, 라인을 넘는 곳(가운데 ±3.6야드 구역 통과)과 야드.

## 판정 기준 (학습 전에 정함)
2M 스텝 시점, 시드별. 합격선은 내 판단이다.
- **옮겨 갔다:** s0, s2(새 공격이 가운데로 가는 시드)에서 구역 통과 50% 이상, 그리고 시드 3개 모두 야드가 같은 실험 fresh보다 1야드 이상 낮지 않다. s1은 새 공격도 바깥(7%)이라 야드만 본다.
- **유효성:** fresh가 s0, s2에서 구역 통과 50% 이상이어야 한다. 아니면 하네스가 EXP-028 분석과 달라진 것이라 판정하지 않는다.
- **해석:** 옮겨 간 가장 작은 칸이 원인이다.
  - warm이 옮겨 가면: 망은 멀쩡하다. 문제는 셀프플레이 일정(수비가 계속 바뀌는 상대) 쪽이다.
  - noise부터: 탐색 부족. 다음은 흩어짐 바닥을 올리거나 세대마다 되돌리기.
  - head부터: 출력층이 굳었다. 다음은 세대마다 출력층 초기화.
  - fresh만: 숨은 층이 굳었다. 다음은 공격을 주기적으로 새로 만들되 수비가 따라잡을 시간을 주는 방식.
- 판정에 안 쓰지만 기록: 4M 시점 결과(시간을 더 주면 옮겨 가나), 0.5M마다 곡선, 구역 안 / 밖 야드.
- 재현: `launch.sh` → `PYTHONPATH=. uv run python experiments/EXP-029-unstick/measure.py`.
