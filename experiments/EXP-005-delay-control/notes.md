# EXP-005 delay-control — 반응 지연 + 태클 통제력 (절반의 실패)
날짜: 2026-11-02 · 기반: EXP-003(셀프플레이), 움직임 비교(`scripts/movement_compare.py`) · 학습 시간: 26.5분 · 스텝: 96M (24단계 × 4M)

## 가설
사용자 질문: "수비가 속도를 조절하고 급하게 방향을 바꾸는 게 안 보인다." 측정해 보니 AI는 감속 0, 꺾는 각도는 NFL의 절반 이하였다.
원인은 물리가 아니라(0.5초에 3yd/s에서 180°, 5yd/s에서 42° 가능. NFL p99와 비슷) **그럴 이유가 없어서**라고 봤다.
1. 반응 지연(0.2초)을 넣으면 페이크가 먹히니 러너가 급회전을 쓸 것이다.
2. 태클 공식에 "통제력"을 넣으면(너무 빨리 들어오면/러너가 옆으로 비키면 놓침) 수비가 접촉 전에 속도를 줄일 것이다(브레이크다운).

## 시도
- `FieldConfig.reaction_delay`: 각 선수는 상대의 위치·속도를 N스텝 전 것으로 본다(자기 몸은 현재). 스크립트 정책도 `sim.seen()`으로 같은 지연을 받음. 기본 0이라 이전 실험은 그대로 재현됨(테스트).
- `TackleConfig.overspeed_weight / sidestep_weight / control_speed`: 수비 속도 4.5yd/s 초과분, 러너가 접근선을 가로지르는 속도만큼 성공률↓.
  보정(스크립트 정책 기준): 통제된 태클은 놓침 10~15%(NFL 수준), 전속력 돌진은 ~35%. 최종값 base 2.3, overspeed 0.25, sidestep 0.2, 지연 2스텝.
- 셀프플레이: 양쪽 모두 처음부터, 러너 먼저. 스크립트 상대 비중 20% 고정(EXP-003의 "스크립트 러너에게 87% 뚫림" 대응). 독주 조기 종료 켬(2yd).
- 움직임 벤치마크 수정: **접촉 전 움직임만** 비교(NFL은 `first_contact` 이벤트 전, 시뮬은 첫 태클 시도 전). 이전 표는 충돌 순간이 "감속"으로 잡혀 있었음.

## 결과
- 접촉 전 움직임 (0.5초 최대 방향전환 중앙값 / 60°+ 비율 / 최대 감속 중앙값):

| | 수비 | 러너 |
|---|---|---|
| NFL 실제 | 27° / 13% / 4.0 | 19° / 4% / 2.5 |
| EXP-003 셀프플레이(R12 vs T12) | 12° / 0% / 0 | 8° / 0% / 0 |
| **EXP-005 R12 vs T12** | 11° / 0% / **0** | **17°** / 0% / **0** |
| EXP-005 R07 vs T07 | 12° / 0% / 0 | 21° / 0% / 0 |

  → **러너의 꺾는 각도는 NFL 수준(17~21° vs 19°)까지 올라옴. 감속은 여전히 양쪽 다 0.**
- 수비의 브레이크다운: **없음.** 태클 시도 순간 수비 속도 중앙값 9.4~9.5 yd/s(전속력), 놓침 65~70%.
- 최신 대 최신 터치다운률: 1단계 이후 75~86%로 러너 우세. 교차표는 [crosstable.png](crosstable.png).
- **수비가 무너졌다.** 처음 1초 뒤 러너에게서 멀어지는 방향으로 달리고 있는 플레이 비율: T01 54~61%, T03~T12 29~36%(개선 없음).
  한 플레이를 프레임별로 보면 수비가 첫 스텝부터 자기 진영 구석으로 대각선 후진(x 15→4, y 28→39), 최소 간격 6.9yd. 러너는 빈 필드를 달릴 뿐.
- 러너 5~7세대 급락: 수비 12세대 상대 터치다운 46→34→31%, **아웃 32→46→51%**. 옆으로 20~23yd 벗어나 사이드라인 밖으로 나감. 8세대에 회복(아웃 3%), 12세대는 옆 이동 3.6yd로 거의 직선.

## 놀라운 점
- **"페이크에 속는 수비"인 줄 알았는데 "도망가는 수비"였다.** 9칸 포스터에서 노란 러너가 직선으로 가고 수비 궤적이 구석으로 빠지는 걸 보고 주크라고 생각했지만, 프레임을 찍어 보니 수비가 처음부터 반대로 달린다.
  추정 원인: 수비 보상은 "러너가 간 야드의 마이너스"뿐이다. 0.2초 지연 + 통제력 벌점으로 수비가 막을 수 있는 플레이가 줄자, 어차피 지는 시작 위치에서는 어떤 행동이든 보상이 같아 학습 신호가 없다. 그 상태들에서 정책이 아무 데로나 흘러감(EXP-004의 "포기하고 구석으로"가 시작부터 일어나는 버전).
  `#story clips/exp005_r12_vs_t12_shorts.mp4` — 수비 12세대가 첫 스텝부터 반대로 달림.
- **러너의 "아웃 사이드라인" 시기.** 5~7세대 러너는 크게 벗어나 사이드라인 밖으로 나갔다. 태클은 안 당하지만 야드를 덜 번다. 8세대에 스스로 고침.
  `#story clips/exp005_oob_dip_vs_final.mp4` — 같은 시작, 7세대(아웃)와 12세대(직선).
  `#story clips/exp005_runner_grid.png`, `clips/exp005_runner_ghosts_shorts.mp4` — 분홍~주황(중간 세대)은 왼쪽 사이드라인으로, 노랑(최종)은 가운데 직선.
- 정정: 지난 비교에서 "스크립트 회피 러너는 53~77°까지 꺾으니 물리는 문제 아니다"라고 했는데, 그 숫자는 충돌 순간이 섞인 값이었다. 접촉 전만 보면 7~13°. 물리 한계는 따로 직접 측정해 확인함(위 가설 참고).

## 다음 시도
수비를 제대로 학습시키는 게 먼저다. 수비가 엉망이면 러너도 페이크·감속을 배울 이유가 없다.
- **수비 학습 신호 보강**(추천): 접근(거리 줄이기)과 골라인 쪽 위치에 작은 보상. 단, 보상 설계 실험이므로 비중을 작게 하고 "도망가는 수비 비율"이 0에 가까워지는지로 판단.
- 지연을 0.1초로 줄여 수비가 막을 수 있는 상황을 늘리기.
- 좁은 통로(필드 폭 축소)로 "옆으로 크게 돌아가기"를 막아, 정면 승부에서 페이크·감속이 필요하게 만들기.
- 3v3로 바로 가기: 수비가 여러 명이면 "어차피 못 막는 상황"이 줄어든다.
