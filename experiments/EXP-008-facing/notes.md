# EXP-008 facing — 몸 방향(엉덩이)을 넣은 1대1
날짜: 2026-11-02 · 기반: EXP-007 설정 + `--facing` · 학습 시간: 26.0분 · 스텝: 96M (24단계 × 4M)

## 가설
사용자 질문: "공격수의 급감속·방향전환이 안 보이는 건 필요 없어서인가?" 주크 검증(`scripts/juke_check.py`)에서 감속은 모든 조합에서 손해였다.
원인 후보 하나: 수비가 원판이라 어느 방향으로든 바로 움직인다. 실제 주크는 수비가 엉덩이를 한쪽으로 돌리게 만들어서 통한다.
→ 몸 방향을 넣으면 (1) 러너가 페이크·감속을 쓸 이유가 생기고 (2) 수비는 엉덩이를 아끼는 법(브레이크다운, 스퀘어업)을 배울 것이다.

## 시도
- **NFL 측정** (`analysis/orientation_from_bdb.py`, 2024 추적의 `o` = 몸 방향, 집계만 `sim/orientation_params.json`에 저장):

| | DB | WR |
|---|---|---|
| 움직일 때 몸 방향과 이동 방향이 90°+ 다른 비율 (백페달·셔플) | 26% | 8% |
| 최고 속도 p99: 정면 / 옆(45~90°) / 뒤(135°+) | 9.0 / 7.8 / 5.7 | 9.2 / 9.3 / 7.2 |
| 엉덩이 회전 p99 (느릴 때 / 8yd/s+) | 252 / 149 °/s | 335 / 174 °/s |
| 느릴 때 가속 p99: 정면 대비 뒤쪽 | 0.78 | 0.87 |

- **물리** (`sim/physics.py`): 몸 방향은 위 회전 속도로만 돈다. 몸 방향에서 멀어지는 쪽으로 밀면 약해지고(뒤로 최대 0.78/0.87배), 그쪽으로 움직이면 최고 속도가 낮아진다(뒤로 0.64/0.78배). 상한을 넘으면 브레이크 힘으로 줄어든다(순간 정지 아님).
- **행동 3번째 값 "스퀘어업" [0, 1]**: 0 = 미는 방향을 봄(달리기), 1 = 상대를 봄(백페달·셔플). 각자 상대의 몸 방향도 관찰한다(0.2초 지연). 관찰 12 → 16.
- `--facing` 없으면 이전과 완전히 같다(기존 테스트 20개 그대로 통과, 새 테스트 5개).
- 손으로 짠 "읽고 반응" 수비는 읽는 동안 스퀘어업. 영상에 엉덩이 방향을 짧은 선으로 표시.
- 셀프플레이: EXP-007과 동일 + `--facing`.

## 결과
- 교차표는 다시 삼각형([crosstable.png](crosstable.png)). 최신 대 최신 69~84% → 마지막 79%. EXP-007(72~78%)과 비슷.
- **처음으로 감속이 나왔다.** 접촉 전 움직임(R12 vs T12, `scripts/movement_compare.py --facing`):

| | 방향전환 중앙값 | 60°+ | 최대 감속 중앙값 | 감속 4+ |
|---|---|---|---|---|
| NFL 수비 | 27° | 13% | 4.0 | 50% |
| EXP-007 수비 | 14° | 1% | 0 | - |
| **EXP-008 수비** | **22°** | 0% | **2.5** | **15%** |
| NFL 러너 | 19° | 4% | 2.5 | 31% |
| EXP-007 러너 | 14° | 0% | 0 | - |
| **EXP-008 러너** | **20°** | 0% | **1.6** | 0% |

- 감속의 출처(`scripts/decel_source.py`): 수비 스텝의 12%가 2yd/s²+ 감속, 그중 **77%는 자기 진행 반대로 민 진짜 브레이크**. 러너는 0.8%뿐(그중 42% 브레이크).
- 몸 사용(`scripts/facing_stats.py`): 수비가 몸 방향과 90°+ 다르게 움직인 비율 0.7%(2세대) → 12% → 20% → 17%(12세대), NFL DB 26%. 러너 5.5%, NFL WR 8%.
  다만 스퀘어업 행동은 초반 세대만 씀(멀리서 0.5~0.8), 12세대는 0. 수비의 "옆·뒤로 움직임"은 대부분 브레이크하며 엉덩이를 트는 동작이다(스퀘어업 백페달이 아님).
- 수비: 태클 순간 속도 9.2 → 8.5yd/s, 놓침 74 → 70%, 도망 18 → 7%.
- 주크 검증(EXP-008 수비 12세대 상대): 감속은 여전히 손해(TD 11% → 6~10%), **반대쪽 페이크 0.4초 후 꺾기는 32%**(회피 11%). 손으로 짠 수비 상대로는 몸 방향을 넣어도 거의 변화 없음.

## 놀라운 점
- **감속은 러너가 아니라 수비에서 먼저 나왔다.** 엉덩이를 돌리는 데 시간이 걸리니, 전속력으로 지나쳐 버리면 되돌아오는 비용이 커졌다. 수비가 접촉 전에 브레이크를 밟기 시작(감속 0 → 2.5, NFL 4.0).
  `#story clips/exp008_r12_vs_t12_hips.mp4` — 엉덩이 방향 선이 보이는 1대1.
- **AI 수비는 페이크에 약하다(몸 방향 유무와 무관).** EXP-007 수비도 10% → 31.5%. 손으로 짠 수비에는 페이크가 손해. 학습된 수비가 러너 움직임에 과하게 반응한다는 뜻.
  그런데 AI 러너는 아직 페이크를 쓰지 않는다(러너 감속 2+ 스텝 0.8%). 수비 전체를 상대로는 전속력 곡선 주행이 더 낫기 때문(79%).
- NFL 측정에서 몸 방향 제약이 생각보다 약하다. 옆으로는 거의 정면 속도(WR 9.3 vs 9.2). 큰 효과는 회전 속도(엉덩이 180° = 0.7초).

## 다음 시도
- 1대1은 여기서 정리. 수비 감속은 생겼고, 러너의 페이크·감속은 1대1 넓은 공간에서는 여전히 필요 없다.
- 3v3: 몸 방향 켜고 시작(`--facing`). 좁은 틈에서 러너 감속이 생기는지 같은 지표로 확인.
