## OL이 그냥 앞으로 돌진한다 (EXP-020 분석)
사용자: "OL 중 몇 명은 앞으로 그냥 돌진해버린다. 끝까지 막거나 경로를 확보해줘야 하는데 안 보인다."
측정(`scripts/ol_jobs.py`, 같은 시드끼리, 러너가 라인 넘기 전까지) — 원본 `experiments/EXP-020-tackle/ol_jobs.json`, `line_hold.json`:
| | 스크립트 OL | AI OL (s0/s1/s2) |
|---|---|---|
| OL 시간 중 블록 중 | 78% | 65 / 67 / 71% |
| 아무도 안 막고 1야드+ 앞으로 나가 있음 | 2% | 16 / 8 / 11% |
| 그때 근처(1.5야드)에 빈 수비가 있음 | 85% | 8 / 11 / 11% |
| 러너가 라인 도달 때 안 막힌 수비(6명 중) | 2.4 | 3.0 / 3.0 / 2.6 |
- 사용자 말이 맞다. 앞으로 나간 OL의 98~99%는 **블록하다가 DL이 벗어난 OL**이고, 82~84%는 계속 앞으로 달린다(평균 2.8 yd/s). 돌아서서 다시 막지 않는다.
- 블록은 OL이 놓아서 끝나는 게 아니라(0%) DL이 벗어나서 끝난다. 중앙값 1.5~1.8초, 러너는 2.6초에 라인 도달. 벗어난 DL은 1초 동안 다시 블록할 수 없다(`reengage_cooldown`). DL이 백필드 1야드+ 들어온 플레이 98~100%.
- AI 러너에 스크립트 OL을 붙이면: s0 0.82 → 1.31야드, s1 0.10 → 1.88야드, s2 1.03 → -0.37야드(s2 러너는 자기 AI 라인에 맞춰져 있음). 블로킹을 더 잘 배울 여지는 있다.
- 원인 후보: (1) 규칙 — 블록이 러너 도착보다 먼저 풀리고, 풀린 뒤 다시 붙을 수 없다. (2) 학습 — 팀 정책 하나가 6명을 움직이고 보상은 야드 하나라, OL 한 명의 행동이 점수에 얼마나 기여했는지 구분이 안 된다(EXP-012 블로커 보상도 효과 없었음).
- 사용자: "추천대로 1번 먼저." → EXP-021 준비: 블록 벗어나는 속도 0.25 → 0.15, 재블록 대기 1.0 → 0.3초. 스크립트 기준 2.5초 블록 유지 65 → 80%. 학습은 맥에서(`experiments/EXP-021-hold/launch.sh`).
