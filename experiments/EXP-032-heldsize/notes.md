# EXP-032 heldsize — 유지 소음은 얼마나 커야 하나
날짜: 2026-11-06 · 기반: EXP-030 조건 A 12세대(늘 한쪽으로 가는 공격), EXP-031 · 학습: 맥(`launch.sh`, 12개 동시, 스레드 1), 약 35분 · 스텝: 공격만 2M, 수비는 12세대로 고정

## 왜
EXP-031에서 소음을 한 플레이 동안 유지하자 반대쪽 시도가 0%에서 37~48%로 뛰었다. 그런데 크기(std 1.0에서 시작해 1.3~1.5까지 커짐)가 평균 밀기만큼 커서 공격이 9세대 동안 아무것도 못 배웠다. 셀프플레이를 다시 하기 전에, 반대쪽으로 옮겨 가게 하면서 배우는 걸 망치지 않는 크기를 짧게 고른다. 사용자: "결과 확인후 다음 방향 추천대로 진행해줘."

EXP-030 A 12세대 공격은 s1, s2에서 늘 오른쪽으로 간다(끝 위치 오른쪽 100%). 그런데 러너를 좌우로 뒤집으면 5.26 → 7.44, 1.51 → 6.89야드다. 반대쪽이 비어 있다. s0은 뒤집으면 줄어든다(5.23 → 3.26).

## 가설
- 매 스텝 소음(지금 방식)으로는 못 옮긴다. EXP-029 warm처럼 자기 방향만 다듬는다.
- 유지 소음은 어떤 크기부터 옮겨 간다. 너무 크면 EXP-031처럼 야드가 무너진다. 그 사이 크기가 있으면 셀프플레이에 쓴다.
- 시험 실행에서 이미 배운 공격에 std 0.5 유지 소음을 걸면 뒤집기율이 0%였다(65k 스텝). 0.5는 모자랄 수 있다.

## 시도
시드 3개 × 4가지. 각자 자기 12세대 수비(고정) 상대로 2M 스텝, 0.5M마다 저장. 하네스는 EXP-029와 같다(`scripts/recovery_test.py`, 환경 512개, 시드 0, 흩어짐 바닥 없음). 망 무게는 모두 같고 소음만 다르다.
| 이름 | 소음 |
|---|---|
| step | 매 스텝 새로(학습 때와 같음, std 약 0.8). 대조군 |
| held05 | 유지(64스텝마다 새로), 시작 std 0.5 |
| held10 | 유지, 시작 std 1.0 |
| held15 | 유지, 시작 std 1.5 (EXP-031 A의 소음이 커진 크기) |
- 코드: `recovery_test.py`에 `--sde-freq`, `--sde-std`(같은 무게로 소음만 바꾸기, `to_sde`), `--flip`(0.5M마다 뒤집기율). 테스트 `test_to_sde_keeps_the_trained_mean`, 80개 통과.
- 측정: 0.5M마다 평균대로 2048플레이(야드, 끝 위치 오른쪽 비율), 흩어짐 켜고 2048플레이(플레이마다 소음 하나), 뒤집기율, 행동 std.

## 판정 기준 (학습 전에 정함)
2M 스텝 시점, 시드별. 합격선은 내 판단이다.
- **옮겨 갔다:** s1, s2 둘 다에서 끝 위치 오른쪽 비율이 50% 이하(시작 100%), 그리고 야드가 같은 시드 step보다 1야드 이상 낮지 않다. s0은 반대쪽이 나쁘니 야드만 본다(step보다 1야드 이상 낮지 않으면 통과).
- **유효성:** step은 s1, s2에서 오른쪽 50% 넘게 남아야 한다. step도 옮겨 가면 고정된 수비 상대로는 매 스텝 소음으로도 옮겨 간다는 뜻이라, 셀프플레이 쪽(수비가 계속 바뀜)이 문제라고 적고 크기 판정은 하지 않는다.
- **선택:** 옮겨 간 가장 작은 크기를 EXP-033(셀프플레이 다시)에 쓴다. 아무것도 안 옮겨 가면 유지 소음은 배운 공격을 못 움직이는 것이라, 세대마다 출력층 새로(EXP-029 head) 쪽을 다음 후보로 둔다.
- 판정에 안 쓰지만 기록: 0.5M마다 곡선, 뒤집기율, 흩어짐 켠 야드, std 변화.
- 재현: `launch.sh` → `curves/*.jsonl`.

## 결과
**판정: 아무 크기도 옮겨 가지 않았다.** 유효성 통과(step은 s1, s2에서 오른쪽 100% 그대로). 유지 소음 0.5, 1.0, 1.5 모두 s1, s2에서 평균대로 뛰면 끝까지 오른쪽이다(94~100%). 미리 정한 대로 다음 후보는 세대마다 출력층 새로(EXP-029 head). 결과 `curves/*.jsonl`, `*.log`.

2M 스텝 시점, 평균대로 야드 / 끝 위치 오른쪽 %(시작: 5.23 / 0%, 5.26 / 100%, 1.51 / 100%).
| | s0 | s1 | s2 | 뒤집기율 s0 / s1 / s2 | 판정 |
|---|---|---|---|---|---|
| step | 8.25 / 0 | 9.38 / 100 | 2.82 / 100 | 0 / 0 / 0% | 대조군 |
| held05 | 7.77 / 0 | 7.80 / 100 | 2.68 / 100 | 0 / 0 / 0% | ✗ 안 옮김 |
| held10 | 5.53 / 0 | 9.08 / 100 | 1.67 / 100 | 0.9 / 0.2 / 10.6% | ✗ 안 옮김, s0 -2.7야드 |
| held15 | 2.09 / 2 | 1.37 / 100 | -0.25 / 94 | 35 / 25 / 55% | ✗ 안 옮김, 야드 -3~-8 |

- **반대쪽을 가 봐도 보상이 없다.** held15 s2는 흩어짐을 켠 플레이의 절반 넘게(뒤집기율 41~55%)가 왼쪽으로 넘었다. 그런데 흩어짐 켠 야드는 -2.45 → -0.61이고, 평균은 오른쪽 그대로다. 같은 공격을 통째로 좌우로 뒤집으면 6.89야드인 그 왼쪽이다. 흔들려서 왼쪽으로 새는 플레이는 OL 블로킹과 맞지 않는 엉성한 플레이라 거기서 야드가 안 나온다. "왼쪽이 비어 있다"는 건 OL과 러너가 함께 왼쪽 플레이를 할 때 얘기다.
- **0.5는 너무 작다.** 이미 배운 공격(밀기 길이 1.25에 붙음)에서는 std 0.5 유지 소음으로 뒤집기율 0%. 매 스텝 소음 0.8과 다를 게 없다. 1.0도 0.2~11%.
- **고정된 수비 상대로는 매 스텝 소음도 잘 배운다.** step은 2M 동안 5.23 → 8.25, 5.26 → 9.38, 1.51 → 2.82야드(EXP-029 warm과 같다). 자기 쪽을 다듬는다.
- std는 학습 중 거의 그대로다(held15 1.50 → 1.40~1.45). 바닥이 없어도 줄지 않는다.

## 놀라운 점
- s2 held15는 흩어짐으로 왼쪽을 절반이나 가 봤는데 평균은 안 옮겼다. 탐색이 반대쪽에 "도착"하는 것만으로는 부족하다. 거기서 제대로 된 플레이를 해 봐야 좋은 줄 안다. 그건 OL 다섯과 러너가 함께 바뀌는 일이라 무작위 소음으로는 거의 안 나온다.
- 그러니 EXP-029에서 출력층을 새로 한 공격이 가운데를 찾은 건 소음 덕이 아니라, 평균이 0에서 다시 출발해 OL과 러너가 함께 새 플레이를 처음부터 맞춰 갔기 때문일 가능성이 크다.
- 클립 없음: 차이는 곡선 숫자로 보인다.
