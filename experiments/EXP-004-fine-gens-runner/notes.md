# EXP-004 fine-gens (러너 + 수비) — 세대 그라데이션 시각화
날짜: 2026-11-02 · 기반: EXP-002(러너 설정 동일), EXP-003(수비 쪽 학습) · 학습 시간: 러너 1.4분 + 수비 1.6분 · 스텝: 각 6M (10만 스텝 = 1세대, 60세대)
수비 쪽 결과물은 [EXP-004-fine-gens-tackler](../EXP-004-fine-gens-tackler/)에 있고, 기록은 이 파일 하나에 같이 쓴다.

## 가설
사용자 요청: "초기 세대에서 나중 세대로 어떻게 진화하는지 색 그라데이션으로 보고 싶다."
EXP-002는 2세대 만에 99%라 체크포인트가 너무 성기다(그라데이션이 "0세대 vs 나머지"로만 보임).
10만 스텝마다 저장하면 진화 과정이 색으로 보일 것이다.

## 시도
- 러너: EXP-002와 같은 설정(PPO, 각도 태클러, ±8yd)으로 6M 스텝, 60세대.
- 수비: `train_runner.py`에 `--side tackler --opponent ckpt:...` 추가. EXP-002 챔피언 러너(gen_025, 결정적) 상대로 6M 스텝, 60세대.
- `render/ghosts.py` 새로 작성: 같은 시작 위치에서 모든 세대를 **한 필드에 동시에** 재생. 세대 색 = plasma 컬러맵(0세대 보라 → 60세대 노랑).
  진화하는 쪽 궤적은 굵게, 상대는 흐리게. ● 러너 ○ 수비 × 태클 지점. 2배 슈퍼샘플링으로 매끄러운 선.
  출력: 9:16 애니메이션 + 마지막 장면 포스터, 9칸 포스터(시작 위치 9곳), `--view/--view-width`로 확대(필드 밖으로 나가는 선은 잘라냄).

## 결과
- 러너 터치다운률(각도 태클러 상대): 0세대 0% → 3세대 47% → 12세대 78% → 24세대 87% → 40세대 99% → 60세대 99.8%. EXP-002보다 훨씬 부드러운 곡선 ([curves.png](curves.png)).
- 수비(챔피언 러너 상대 터치다운률, 낮을수록 수비 승): 0세대 100% → 4세대 78% → 12세대 65% → 20세대 61% → 60세대 59%. EXP-003 균형점(~60%)과 같은 곳에 수렴 ([../EXP-004-fine-gens-tackler/curves.png](../EXP-004-fine-gens-tackler/curves.png)).
- 렌더 비용: 61세대 애니메이션 12초 분량 약 45초, 9칸 포스터 약 8초.

## 놀라운 점
- **러너가 진화 도중에 전략을 바꿨다.** 시작 위치 2번에서: 0~37세대는 출발하자마자 잡힘(보라~분홍 ×들이 시작점에 몰려 있음), 38~51세대(주황)는 **오른쪽**으로 돌아 득점, 52~60세대(노랑)는 **왼쪽**으로 바꿔 득점.
  같은 시작에서 "답"이 하나가 아니고, 학습이 한 답에서 다른 답으로 옮겨 감.
  `#story clips/exp004_runner_ghosts_shorts.mp4` (+ .png 포스터) — 61세대 동시 재생, 오른쪽 길(주황)과 왼쪽 길(노랑)이 갈라지는 U자.
  `#story clips/exp004_runner_grid.png` — 9곳 포스터. 대부분의 시작에서 궤적이 세대가 갈수록 한 줄로 모임.
- **못 잡을 상황이면 수비는 포기하고 구석으로 간다.** 9칸 포스터에서 러너가 결국 득점하는 시작들(TD 61/61)은 수비 궤적이 전부 왼쪽 아래 구석(자기 진영 사이드라인)으로 쏠림.
  수비 보상은 러너가 몇 야드 가는지에만 달려 있어서, 놓친 뒤 어디로 가든 상관이 없기 때문. 뒤쫓는 태클(chase-down)이 학습될 이유가 없다 → 3v3부터는 다른 수비수가 있으니 "끝까지 쫓기"가 의미 있어질 것.
  `#story clips/exp004_tackler_grid.png`
- 수비 쪽 진화(시작 위치 2번): 0~15세대(보라)는 엉뚱한 방향으로 가서 러너가 득점, 16세대부터(분홍→노랑) 러너 진로로 가서 태클.
  `#story clips/exp004_tackler_ghosts_shorts.mp4` — 확대 화면(24×20yd).
