# EXP-033 headreset — 세대마다 공격 출력층을 새로 (진행 중)
날짜: 2026-11-06 · 기반: EXP-030 조건 A(EXP-028 A 규칙, 교체 없음, 밀기 묶기 1.25, 새 공격 리그 0.2, 매 스텝 소음), EXP-029, EXP-032 · 학습: 맥(`launch.sh`, 조건 2개 × 시드 3개 동시, 스레드 2) · 스텝: 세대당 공격 2M + 수비 2M + 새 공격 2M, 12세대

## 왜
- EXP-032: 유지 소음은 어떤 크기로도 배운 공격을 옮기지 못했다. 흔들려서 빈 쪽으로 새는 플레이는 OL과 맞지 않아 야드가 안 나온다.
- EXP-029: 출력층만 새로 한 공격은 2M 스텝 안에 새 망처럼 가운데를 찾았다(-6.4 → 0.5M 4.6 → 2M 8.4야드).
- 지금 공격은 1세대에 고른 쪽을 끝까지 안 바꾼다. EXP-030 A에서 라인을 왼쪽으로 넘는 비율(`explore_side.py`, 1 / 3 / 6 / 12세대): s0 100 / 100 / 100 / 100%, s1과 s2 0 / 0 / 0 / 0%.
- 미리 정한 다음 후보(EXP-032 notes). 사용자: "결과 확인후 다음 방향 추천대로 진행해줘."

## 가설
- 출력층을 새로 하면 평균 밀기가 0에서 다시 출발한다. OL과 러너가 그 세대의 수비에 맞는 플레이를 처음부터 함께 맞춘다. 수비가 한쪽으로 쏠렸으면 다른 쪽을 찾는다. 숨은 층(배치를 보는 부분)은 남아서 처음부터 하는 것보다 빠르다.
- 걱정: 매 세대 -6야드에서 다시 시작하니 2M 스텝 안에 다 못 배울 수 있다. 그러면 수비가 덜 배운 공격만 상대하게 된다. 그래서 B는 3세대마다 한다.
- 자신은 반반보다 조금 낮다. 길은 옮기겠지만 배치를 읽는 데까지 갈지는 모른다.

## 시도 (규칙은 EXP-030 A와 같음. `config.yaml`로 확인)
- `train/selfplay.py --reset-head-every N`: 공격 2세대, 2+N세대, ...를 배우기 직전에 출력층을 새 망처럼 초기화하고(직교, gain 0.01, 편향 0) 흩어짐 std를 1로 되돌린다. 숨은 층, 가치망, 최적화기 상태는 그대로(EXP-029 head와 같다). 새 공격 리그와 수비는 바꾸지 않는다.
- A: `--reset-head-every 1` 매 세대(2~12세대).
- B: `--reset-head-every 3` 2, 5, 8, 11세대.
- `reset_head`를 `train/policies.py`로 옮겼다. `explore_side.py`에 왼쪽으로 넘는 비율을 더했다. 테스트 80개 통과.

## 판정 기준 (학습 전에 정함)
12세대, 조건별, 시드 평균. 합격선은 내 판단이다. 기준값은 EXP-030 A.
| 지표 | EXP-030 A | 합격선 |
|---|---|---|
| 유효성: 1, 3, 6, 12세대 사이 왼쪽으로 넘는 비율이 50%p 넘게 바뀐 적 있는 시드 | 0 / 3 | 2 / 3 이상 |
| 1. 좌우 전환 | 0.00 / 0.00 / 0.00 | 평균 0.5 이상, 그리고 시드 2개 이상 0.5 이상 |
| 2. 실제 러너 야드 ≥ 같은 수비 상대 단순 러너의 스냅 때 읽기 야드 | 2 / 3 | 시드 3개 모두 |
| 유지: 새 공격 터치다운 | 56% | 86% 이하 |
| 유지: 수비 접근 | 64% | 60% 이하 |
| 유지: OL 혼자 달리기 | 1% | 2.5% 이하 |
| 유지: 다시 블록 | 57% | 55% 이상 |
| 유지: `lb_early_free` | 4.3% | 11% 이하 |
| 안전장치: 같은 시드 터치다운 / 시간 초과 | 58 / 59 / 26% / 0% | 시드마다 20~70% / 5% 이하 |
| 안전장치: 이 러너 vs 스크립트 수비 / 스크립트 러너 vs 이 수비 | 98% / 13% | 90% 이상 / 30% 이하 |

- 유효성을 못 넘으면 초기화가 길을 옮기지 못한 것이라 1, 2번은 판정하지 않는다.
- 1, 2번이 질문이다. 1번만 넘고 2번을 못 넘으면 엉뚱한 쪽으로 바꾸는 것이라 불합격. 1번 평균이 0.2~0.5면 "진전"으로 따로 적는다.
- 조건 비교: 둘 다 합격하면 좌우 전환이 높은 쪽, 같으면(차이 0.1 이하) 초기화가 적은 B. 하나만 합격하면 그쪽.
- 판정에 안 쓰지만 기록: 세대별 왼쪽 비율과 구역 통과(1, 3, 6, 12세대), 본 공격 / 새 공격 야드(`metrics.csv`), 밀기 길이와 각도, 러너 좌우 뒤집기 야드, 읽기 가치, LB 추격.
- 재현: `analyze.sh A`, `analyze.sh B`(EXP-031 것과 같다).
